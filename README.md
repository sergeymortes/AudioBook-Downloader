# AudioBook Downloader

Приложение для Windows, написанное на Python.

## Возможности

- Графический интерфейс с тёмной темой.
- Загрузка аудиокниг по ссылке.
- Автоматическое определение количества аудиочастей.
- Выбор папки сохранения.
- Отображение прогресса загрузки.
- Проверка обновлений через GitHub (в разработке).

## Технологии

- Python
- CustomTkinter
- Requests
- BeautifulSoup
